How this record stays public-safe

Why the source behind these pages stays private, and how only the finished pages are ever published.

TL;DR: Everything you're reading is written in a private repository. An automated job builds the site, sends only the finished pages to a public repository, and reads every one of them first. If anything in them is something no machine or person has read, the publish stops.
How it works, step by step

Two repositories, one direction

There are two repositories behind these pages:

  1. changelog-astro (private): the entries, the drafts, the write-ups and the site’s code.
  2. changelog-astro-public (public): only the finished pages, which GitHub Pages serves.

Nothing ever flows from public back to private, and nobody edits the public one by hand.

What happens on every update

When an entry is saved to the private repository, an automated GitHub Action (a small job GitHub runs by itself):

  1. Builds the site into plain pages.
  2. Checks that the list of what may leave (PUBLIC-ALLOWLIST.txt) names one thing only: the built pages.
  3. Copies just those pages aside, and refuses anything that looks like a key, a password or a private note.
  4. Reads every file it is about to publish. Words are read for anything sensitive; pictures and fonts are allowed only in their own assets folder. Anything it can’t read stops the whole job.
  5. Pushes the pages to the public repository as one ordinary change, with a key that can write to that one repository and nothing else.

Why go to this trouble

A home’s notes can brush against things that are nobody’s business: drafts, ideas he hasn’t seen yet, who set what up. Writing in private and publishing only the finished, reviewed pages means a draft or a stray note can’t become public by accident. The rule for what gets an entry at all is simple: if it can’t be said in public, it doesn’t get one.

What these pages don’t do

They set no cookies, run no analytics, and load nothing from another site: the fonts, the icons and the welcome are all served from here. They ask search engines not to list them, as his own site does, until TMade Alex says otherwise.
